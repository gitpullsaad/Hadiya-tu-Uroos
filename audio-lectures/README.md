# Audio lectures — Hadiya-tul-Uroos (ہدیۃ العروس)

English audio lectures on *Hadiya-tul-Uroos* by Hafiz Mubashir Hussain Lahori: one per chapter, plus an introduction and a whole-book summary.

The lectures are based **only** on the study notes in `.claude/skills/hadiya-tul-uroos/references/notes.md`. They paraphrase the book; they don't quote it. Page numbers are the book's printed pages (PDF page = printed page + 2). They explain what the book says and are not a fatwa.

- `mp3/` holds the audio files.
- `scripts/` holds the full transcript of each lecture, so you can read along.
- `make_audio.py` rebuilds the MP3s from the scripts, using the offline Kokoro voice model. The usage notes are at the top of the file. After you edit a script, re-run it and only the changed lectures are rebuilt.
